# Aerowise — Product Spec v0.2

This repository is a product specification for an all-in-one operating system for the Texas aerobic septic maintenance market.

## Product thesis

Build an all-in-one operating system for aerobic septic maintenance providers.

The software should replace the provider's current mix of:

- customer/site records
- recurring maintenance contracts
- inspection scheduling
- technician field forms
- county report generation and filing
- renewals and e-signatures
- invoices and payments
- customer communications
- route planning
- QuickBooks handoff/sync

The product should feel complete enough to replace an incumbent, but deliberately avoid becoming a generic field-service platform.

## Core promise

> Run the maintenance side of the business in one place. The office handles exceptions, not paperwork.

## Differentiation

1. faster onboarding and migration
2. better technician mobile experience
3. offline-first field work
4. stronger renewal automation
5. cleaner QuickBooks integration
6. more automatic compliance filing
7. proof-of-filing / compliance ledger
8. simpler architecture and UX
9. better customer portal
10. multi-jurisdiction foundation
