# UX-FLOWS.md

## 1. Owner home

Top row:
- inspections due
- overdue
- filings at risk
- contracts expiring
- unpaid balance

Main body:
- Exceptions requiring attention
- Today's routes
- Renewal pipeline
- Recent activity

Do not default to a generic CRM dashboard.

## 2. Office scheduling

Left:
- unscheduled recurring obligations

Center:
- technician calendar / route columns

Right:
- map and constraints

Actions:
- drag to technician/day
- bulk schedule
- route group
- customer notification

## 3. Technician day

Screen:
- Today's route
- stop count
- next stop
- sync status

Stop card:
- address
- navigate
- access/gate
- dog warning
- customer scheduling requirement
- system type
- last inspection issue

## 4. Inspection

Step 1: arrive
- auto timestamp
- GPS
- access issue option

Step 2: inspect
- large pass/fail controls
- numeric readings only where needed
- conditional fields
- prior reading visible
- required photos inline

Step 3: issues
- repair needed?
- pumping?
- parts?
- notes/voice note

Step 4: review
- missing requirement warnings
- customer signature if needed

Step 5: complete

After completion:
- sync
- generate report
- file
- customer notify
- next due

Technician sees success and moves on.

## 5. Compliance screen

Columns:
- Due soon
- Completed / preparing
- Ready
- Sent
- Confirmed
- Failed / rejected

Primary filter:
"Needs attention"

## 6. Renewal flow

Office:
- upcoming renewals
- sent
- viewed
- signed
- paid
- activated
- failed

Customer:
- one link
- confirm contact info
- choose add-ons
- e-sign
- pay
- confirmation

## 7. Customer portal

Magic link:
- contract status
- next visit
- last report
- report history
- invoices/payments
- renewal
- service request

## 8. QuickBooks conflict center

Show only:
- failed sync
- ambiguous match
- deleted/archived mismatch
- changed in both systems

Each exception gets:
- explanation
- recommended action
- retry button
